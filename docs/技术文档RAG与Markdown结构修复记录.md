## 已确认的问题与修复

1. **协议标识被当作测量值。** 已存单文档失败回答引用中的HTTP版本及状态行，被要求额外填写数值适用限定。grounded-number-roles-v5将显式HTTP版本、标准状态行和带HTTP标签的状态码作为类型化字面量，逐条核对本论断实际引用。版本或状态不符仍拒绝；协议数字不能为金额背书，反引号也不能豁免金额、时长或连接数。
2. **分析标签被当作题干事实搬用。** source-phrase-layout-v4只允许已声明inference的短组合分析名词，且各组成项必须在本论断实际引用中有支持。数值、用户经历、否定命题、文档命名式表述及direct／synthesis仍不走该例外。ASCII词检查完整词边界。成对Markdown行内排版只在匹配视图中消除，原始引用和偏移不改。
3. **Markdown表格与代码被当成普通段落切分。** local-markdown-3识别标题层级、管道表格及代码围栏；structured-heading-table-v6将表格按完整数据行携带原表头分块，头与行分别记录原文位置。转义竖线和行内代码中的竖线不作为列分隔符。代码不混入正文，长代码仅在物理行边界续分并保留缩进及共同块身份；不把续片宣称为完整程序。分隔横线保留在原结构中，但不单独进入检索。
4. **超限行为明确。** 表头连同单行、表头自身或单行代码超过上限时，明确失败并提示调整长度，不从行中间裁掉机制或参数；旧解析版本和分块保持。未闭合围栏保留到文件末尾，围栏内的标题符号不当作章节。文档中的代码、命令、HTML及链接均只作为资料，不执行。

提示词同步说明协议字面量、真实数值、分析标签和原文引用的职责，禁止把题干措辞作为原文名称；没有添加额外润色或自动重试调用。Markdown原始表行保持文本证据回退，不冒称已有PDF／XLSX坐标投影；其结构与来源进入任务冻结签名。
