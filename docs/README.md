## 如何维护

一个事实只在所属阶段更新：发布／main在05，语义／预算在04，工作项在07。其他阶段引用它，不复制“当前最新”长段。新增问题补触发条件、实现边界、实际证据与待验范围；CI、引用可追溯和语义正确分别判定。

原A01～A26、38项工程编号、6项产品事项和产品验收场景保留映射，旧失败不改判。归档按原字节及SHA-256保护；当前导航和版本检查用`python scripts/check_docs.py`，链接检查不证明正文语义或持续在线。
