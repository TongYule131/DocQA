# 阶段02：检索、理解与问答契约

当前源码／版本和功能开关见[阶段05](阶段05-代码审查与加固.md)及[README版本表](../README.md#实现版本)，本页维护行为，不复制发布史。

## 会话与执行范围

客户使用统一/app会话。单文档问答是当前知识库的资料筛选；换库新建会话。旧文档会话和独立结果通过适配保留原身份、来源与预算，不重新生成；未归库资料明确提示准备状态。

当前问题、已确认对象／条件、材料引用、来源轮次和未答子问形成有界理解。近期问题摘录和用户笔记只是用户线索，助手旧回答不是新事实。停用、清除、更正、撤权及到期改变epoch，旧计划不能复活旧状态。

业务意图决定动作与资源；概览、事实、比较、因果、边界、概念及公式核对决定证据需求。纯交互零外调，混合业务不被礼貌前缀截走；不明指代先澄清。未接入实时源明确缺数据，复杂混合请求先确认范围。工具补参绑定原意图、工具版本及已确认参数；不能换实体或扩权。

## 固定输入与检索

每个任务固定授权资料、解析／索引版本、配置、问题、计划和预算。关键词、向量、结构与相邻线索参与实际候选契约，保留原始排名和类型化淘汰原因；通道分数不冒充语义概率。

召回、排序截断、装入、可见原文和经过校验的引用分开计量。定义、例外、阶段标签、比较双方及数学公式／解释／条件按必要组核对；预算不足不使用半组拼结论。只有完整索引文本实际装入才称完整阅读，否则仅为入选范围。

只读冻结回放使用保存的真实查询向量、来源、质量、策略与预算；不能给新文本套旧向量、改输入哈希或把缓存复放称新生成。可选精排及模型问题规划须有独立成本和验收，状态见阶段05。

## 生成、数字和引用

复杂题可以先规划选材和段落，再一次写作；每步分别预扣请求。组织先直答中心判断，再沿原因、机制、同维比较、条件／边界推进。原文仅并列时不补因果，不增加付费润色调用。

输出遵守严格结构、事实类型、条件、覆盖和逐字原文范围。阶段名称必须绑定本阶段实际证据；比较联合论断同时具有双方依据。用户经历和题干措辞不能冒充文档事实，精确引用也不自动证明语义支持。

地址、变量上下标、答案列举、HTTP协议字面量和真实数值分层核验。协议版本／状态须在本条实际引用中有支持；金额、时长、比例、连接数等继续检查适用限定。反引号不能豁免数值，协议编号不能为业务金额背书。

分析者短组合标签只允许声明inference且组成概念受本条引用支持；direct／synthesis不走该例外，不能写成原文命名。成对行内排版只在匹配视图中归一化，不改原始引述、字符偏移或历史答案。

## 流式与恢复

完整局部事实到达后先核验、持久化事件，再展示生成中；不显示思考、半截JSON或未校验文字。局部块不是正式整篇回答，最终仍核对协议、覆盖和引用。失败、取消、截断及中断保留未完成状态。

SSE按游标读取已存事件并重验账号／资料范围，刷新不领取任务或重新生成。请求幂等、租约令牌、检查点和逐请求预算跨重启保持；不确定的在途请求进入需处理状态，不自动重发。

## 工具与反馈

只读工具须管理员登记、当前库授权、配置／凭据和参数有效；Schema为有限基础类型子集，布尔与数值枚举不混同，参数长度有硬上限。未登记的真实接口不虚构结果。工具来源与文档引用分开。

反馈默认不分享正文。客户逐单授权最小复现包；撤回收回后台正文。回归案例、原失败和独立负例绑定代码／输入／审核代次，任意文字或旧报告不能用于关闭新修复。临时内容到期后的物理清理要求见[阶段03](阶段03-稳定版工程与恢复.md)。

## 意图的产品职责

意图要形成可执行决策：用户要做什么、对象和条件是什么、可以使用哪些资料／工具、是否缺参数或缺数据，以及如何回应。业务节点必须改变资源、约束或动作；论文的每个知识点不需要管理员手建一个节点。确定性规则、可选语义排序和查询规划是组件，不能用其中某个标签分数代替整问完成率。

提交、worker与测试台使用同一决策；规划不能扩展授权范围。未接入实时业务源明确说明缺少数据，不虚构查询结果；混合知识／实时请求先确认范围。只读工具补参必须绑定原意图、工具版本、已确认实体和参数，刷新、取消、撤权及跨账号不能复活确认。

参考项目的结构思路只作历史依据，原对比及固定源码索引在归档；DocQA按自己的资料、权限、任务和预算契约验收。没有部署参考项目或同集对照，不声明双方准确率／性能胜负，也不声称具备任意多动作编排。

## 长答案的组织与修复边界

先直答核心判断，再按证据允许的关系推进；每段提供新信息，定义、背景和结论不反复重述。清单和操作步骤仍可分项，不把所有题硬改成一套段落模板。

| 问题 | 应完成的组织责任 | 必须防止的错误 |
| --- | --- | --- |
| 多跳解释 | 连接判断、机制、前提与适用范围 | 三段摘录并列后让读者自行补因果 |
| 比较 | 同一维度比较双方，并共同引用联合论断依据 | 各写摘要后凭空添加差异原因 |
| 概念结构 | 先辨别分类依据，再说明交叉／层级／支持关系 | 因数量相同强制一一映射 |
| 否定／边界 | 区分题干命题、推出关系及例外 | 有局限写成失效、能缓解写成不必治理 |
| 数据／公式 | 保留主体、口径、期间和公式／正文冲突两端 | 自报体验升级为因果证明、自动替作者改公式 |

选材计划和展示编排都不是事实来源。展示层只分组／排序已校验事实，不引入自由的新标题、数字或关系论断；旧答案按原协议读取，不批量润色。生成中的局部块和最终整篇使用各自校验范围，最终覆盖不因局部通过而跳过。

不能为了更流畅删限定、拼接不连续quote、从题干补文档命名，或再调用一次模型无约束改稿。HTTP协议字面量仍需本条实际引述支持；金额／期限／比例继续核对适用条件。相同输入零HTTP复放只能证明守卫行为，不能证明新索引上的模型生成质量。
