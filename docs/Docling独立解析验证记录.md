- NVIDIA RTX 4060 Laptop，显存 8188 MiB；已通过 CUDA 容器中的 `nvidia-smi` 验证。
- 宿主机与容器报告的驱动版本字符串有所不同，不能仅据此认定错误；推理库能否运行另行验证。
- 实际找到 7 份样本，说明文件列出的 `08-text-zh-course-note.pdf` 不存在。
- 样本原件位于项目外部；清单和解析输出位于 Git 忽略的 `data/docling-validation/`。

页面与 Office 内容抽查补充：

- 01 第 2 页渲染后确认为单栏正文。
- 03 第 12 页渲染后确认为可见空白页，不能因这一页没有文本就拒绝整份文档。
- 04 第 1 页是带人工噪点的编委会名单，适合核对中文姓名，不应把 DOCX 中的经营数字当作这一页的答案。
- 07 的 B8:F8 含 5 个 SUM 公式，但文件没有保存公式计算缓存。解析器若只读取缓存，会得到空值；不能将其误判为 OCR 丢字，也不能假称已经计算出结果。

## 验证方案

- 固定官方镜像版本 `v1.34.0`，正式 GPU 验证使用安装 ORT GPU 1.30.0 的派生镜像。
- 已核对两个官方仓库中的 linux/amd64 镜像清单摘要一致：`sha256:42318951f7fb70bea50907c3cdd6b36d15713a55907bd91ab354abc935455675`。
- 使用异步提交、轮询、结果领取；明确请求 `rapidocr`。
- 模型缓存使用独立命名卷；业务 `.env`、数据库和密钥不进入容器。
- 客户端保存原始 JSON、Markdown、任务编号、文件哈希、处理时间及最终转换状态。
- 客户端模拟 HTTP 验证：完整成功、部分成功的区分、远程 URL 拒绝，以及提交响应丢失时不重复投递，共 4 项通过。此项不代表真实解析通过。
- `deploy/docling/validate.ps1` 已改为检查本地派生镜像并仅执行 GPU 验证；必须包含 OCR GPU 覆盖配置。状态记录在 `data/docling-validation/stage1-status.json`，日志记录在同目录 `stage1.log`。历史状态文件不是当前服务的实时监控。
