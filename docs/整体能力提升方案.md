## 下一批优先顺序

| 优先级 | 工作 | 验证出口 |
| --- | --- | --- |
| P0 | B2概览与多轮对象理解 | 主题／结构／结论／限制覆盖，明确比较对象和用户条件；关闭记忆、切换账号／资料不串内容，旧回答不当证据 |
| P0 | 运行与数据保护 | 诊断三个角色意外退出，明确可靠启动方式；异常退出告警、完整资料备份／实际恢复，保持请求幂等与不确定调用不重发 |
| P0 | 独立新资料／新问题验收 | 推理前复核并冻结原件、关键数字、联合证据组和禁止推断；已用题作回归，事实／引用／条件／覆盖分别评分 |
| P0 | 逐事实语义支持与性质声明 | 已有原文身份／连续范围检查继续保持；复核direct／synthesis／inference，不能用精确匹配替代蕴含判断 |
| P1 | 跨文档冲突与最短充分证据 | 定义优先和必要槽位不漏，避免长段冗余；冲突保留版本与适用条件，不拼成无依据结论 |
| P1 | 反馈、配额与质量看板 | 反馈可回溯处理结果；用户／全局用量不可绕过，token未知保持未知，工程成功率与语义成绩分开 |
| P1 | 扫描表格／文字／阅读顺序 | 编号、符号、长格漏字、跨度、空白与0分别验；原生和扫描分开，不让实验候选成为正式事实 |
| P1 | 页面分流与补检 | 等有效像素消融，验证去重召回损失与误增；原图独立复核关键数值，图中文字与箭头关系分开 |
| P1 | 性能与费用 | 无缓存解析→检索→首块→最终完成，完整HTTP／token／设备资源；单题时序不称P95，不预设扩大上下文收益 |
| P2 | 摘要／提取深化 | 重要例外、指标别名确认、多层汇总和完整资料恢复；按需求另冻样本和范围，不自动扩收费任务 |

## 质量闭环

1. 冻结原件、标签、问题、必须证据、不得推断事项和分组；关键标注用原始像素独立复核。
2. 保留基线、变量、实际输入和首次失败，不看输出后改预期凑通过。
3. 定位后资料即转开发回归，不再称独立盲测；新增文档／模板分组报告。
4. 分开报告工程、引用可追溯、语义支持、条件、覆盖及未验证项，不合成掩盖严重错误的总分。
5. 变更OCR／分块／检索／Prompt／流式后仅做相关必要回归；新增默认策略须通过相应真实质量门槛。
