当前发布／CI只见[接力说明](稳定试用版接力说明.md)，工程标准见[主任务书](稳定试用版分阶段工程任务书.md)。本页记录本轮确认的问题与证据，避免把旧阶段摘要重复放进每个入口。

## 本轮范围

用户授权检查bug并直接修复，更新README、整合混乱文档；完整候选通过GitHub CI后可提交并正式部署。保留原修改、正式资产、旧结果、失败和账本。本地只做关联定向，不执行未获准的本地全量，不新增模型调用。

已对170份app／scripts Python源码作AST检查，审查Windows启停、维护／清理、工具登记／参数、反馈分享／权限和文档核验，并结合原有权限、恢复、流式及相关定向检查。AST检查不等于逐行语义审计；本轮不宣称全仓库不存在其他bug。

## 已确认问题

| 编号 | 触发与影响 | 修复／回归 |
| --- | --- | --- |
| AUD-01 | 监管器或某角色JSON损坏／PID无效，停机脚本提前退出，后续健康角色未停止 | 先设置本目录手停标记，逐角色隔离错误；继续停止可核实自身进程，保留坏记录并非零退出。双PowerShell真实子进程负例 |
| AUD-02 | 临时库清理后，已确认澄清对象／参数仍留在choices_json | 清空私有确认值并取消状态，保留确认键／哈希墓碑；实际澄清→确认→到期清理回归 |
| AUD-03 | 旧临时附件物理清理后，流式草稿和反馈／复现正文仍残留 | 统一清除旧／新临时资料的问答辅助正文及分享，保留费用和请求历史；真实流式及反馈HTTP链回归 |
| AUD-04 | 清理错误／未初始化目录会建立空库，且清理前未核验旧schema或结构 | 在维护写入前拒绝缺库，在文件删除前只读核验当前结构；支持的备份历史版本不等于可用当前代码清理 |
| AUD-05 | Python枚举相等把True与1混同，错误类型或永远无法满足的参数约束仍能登记 | 类型敏感JSON枚举比较、逐项验证及最小长度／数量硬上限；不先调用模型提取再失败 |
| AUD-06 | 无效端口未在工具登记前拒绝，坏IPv6产生未处理ValueError | 登记前解析地址／端口并安全422拒绝，不访问数据库、模型或业务接口 |
| AUD-07 | 对合法大整数调用math.isfinite会溢出，Schema／参数检查异常 | 仅浮点作有限值检查，整数保持精确范围比较；布尔／数字仍分开 |
| AUD-08 | 当前文档重写后，原冻结路径被当前文件抢先匹配，历史哈希验证失败 | 按期望哈希选择相应归档；当前链接仍核验，历史快照必须位于archive且字节校验通过 |
| AUD-09 | uploads／parse-results祖先为Windows目录联接时，仅检查最终文件可允许目标越出数据目录 | 清理前拒绝存储／维护根路径别名，逐目标核验仍位于显式数据目录；真实NTFS目录联接隔离负例 |

原始失败报告在data/project-audit-20261026/：probes-before.xml、probes-stop-legacy-before.xml及probes-purge-schema-before.xml。首次旧附件测试被隔离环境遗留ready阻断，修正夹具关闭／移除自己的标记后再次复现真实残留；首次旧库夹具整轮回滚为v0，已改为实际v14副本，均保留原报告。
