## S2：候选契约、融合归因与冻结对照

实现文件：`app/retrieval_channels.py`、`app/retrieval_planning.py`、`app/rag_pipeline.py`、`app/frozen_retrieval.py`。

统一 ChannelResult 保存文档／解析版本／块身份、通道、原始分数、通道名次和策略版本。同一候选的 vector／lexical／structural 命中均保留，单独记录最终入选理由和精排前后名次；原始通道分数不跨通道当作正确概率。后台链路只投影固定通道与淘汰计数，不展示问题、块正文或原文身份清单。

全局装入后重新计算实际 admitted_count。无候选、排序排除、质量、阈值、预算、去重、绑定组不全和无法归因的丢弃分别记录；无法归因不会假装成预算原因。沿用原有槽位、数学组和跨页续句保护。

可选 Reranker 只能返回同一冻结候选的精确排列；受保护候选优先，不能增加来源或删掉绑定成员。当前提供精确输入哈希的本地 ReplayReranker，默认关闭；回放不匹配时保留原排序，不外调。回放文件内容哈希进入任务配置签名。尚未选择／启用真实语义精排供应商，因此不宣称真实精排收益。

冻结对照文件固定文档组、原问题、解析／索引快照、查询向量、候选原分、预算及必需证据组；修改后哈希失效。离线报告分别统计候选、精排后、装入、可见范围及已验证引用的组存活情况。没有已验证引用记录时 quoted_groups 为 null。合成工程案例必须标 synthetic，不冒充人工标注。60题跨文档人工开发／校准／保留集仍未建立，不伪造这一语义验收出口。

## S3：受控术语、实体与按需规划

实现文件：`app/query_understanding.py`、`app/entity_memory.py`、`app/conversation_memory.py`及现有提交／执行路径。

保留原问题及固定授权快照，术语只追加本地受控映射，不替换否定词、实体或数字。长追问从最多30个成功用户轮次提取最多12个实体，保存来源轮次和比较对象；不读取助手回答作证据。用户可查看、修改、清除实体，编辑与提交使用会话 revision／memory_epoch 保护。清除或停用后不再回读旧 epoch，旧记录保留审计。显式更正／撤销形成实体和滚动摘要的边界。

可选滚动摘要是有来源轮次和输入哈希的用户问题摘录，默认关闭，无模型调用，不是文档事实。仍需从本轮获授权资料重新检索并校验事实。旧单文档会话保留兼容协议；新统一会话使用带实体的上下文。

可选模型查询规划默认关闭，仅在知识库工作任务中执行一次，并预扣／记录 query_planning、保存检查点；它与既有“选材及段落编排”是两个阶段。仅接受原问题／明确实体中的连续词句，不能输出范围字段或新数字、新实体。确定失败回到原问题并保存空规划，不自动重发规划；不确定请求仍转 needs_attention。预期供应商请求数包含该可选一次。

## S4：分层校验、反馈与回归闭环

保留已发布的逐论断协议、原文／数值／条件硬闸、direct／synthesis／inference 支持复核和确定性正文呈现，不新增“校验通过即语义全对”的承诺。

`/api/feedback` 提交／读取本人反馈，类型涵盖数字单位、引用页码、遗漏、未回答、来源冲突、表达和有帮助。刷新／查询／导出不发模型请求。客户默认不分享问题和回答；只有逐单勾选后，管理员详情才能查看提交时的本题快照，列表仍只显示最少元数据。分享可撤回，撤权后本人仍可撤回；反馈本身不授予业务原件或其他会话访问权。

`/admin/feedback` 与 `/api/admin/feedback` 提供处理入口。open→reproduced→fixed→verified→closed 逐步推进；复现需要根因，修复需要回归样本编号，验证／关闭必须同时保存原失败和独立负例的复验证据。允许重新打开，使用 revision 防并发覆盖。记录人工审核流程，不自动写入知识库、训练集，也不把填入证据编号当成独立语义认证。

## S5：配额、排队、熔断、缓存与恢复

统一会话等待资料的提交、知识库任务、旧单文档问答和分析任务纳入短事务排队配额。幂等原请求在配额检查前复用，不因刷新再占队列。待资料请求转为任务时扣除自身等待条目，避免双计。领取时检查用户／全局活动数，按用户最近一次开始时间和提交时间轮换；原有任务租约与不确定调用恢复逻辑保留。

供应商适配器对每次生成／流式和每个 embedding HTTP 批次统一检查用户／全局并发、UTC 日累计额度和模型／网关维度熔断。失败及不确定请求保留计数；熔断或配额拒绝不发 HTTP。到期后最多一个探测请求，不透明切换或自动重试均未引入。GET `/api/chat/quota` 可查看本人配额；管理员 `/api/admin/operations` 查看总量、熔断和运行状态，不返回客户正文。

只缓存已校验向量的不可变解码，键包含数据目录、文档、解析／索引、来源／供应商签名以及本次向量字节哈希。每轮仍读取并核对当前权限、索引、来源和向量；缓存不能绕过撤权或使用被篡改的字节。默认32MB，有界淘汰，0禁用。不引入 ANN、Redis、独立数据库或依赖更新。

`app.local_supervisor` 复用已有身份核对后的 Windows 启停入口，锁保护单实例、检查三角色就绪；十分钟最多恢复三次。代码／schema 变化、启停失败会 needs_attention，不自动迁移库或重发不确定调用。手动 stop_local 先写停止标志防止反复拉起。显式安装 `scripts/install_resident.ps1` 才注册当前用户登录后的计划任务，pythonw 隐藏窗口，注销后不驻留；本轮未安装正式任务。日志在角色停止后轮转，最多保留上一份。此方案不等于机器启动即无人登录的 Windows 系统服务。
