# OCR 识别量化标准与提升计划

冻结日期：2026-10-19。此标准先于本轮 OCR 推理和 medium 对照结果制定。只做本地隔离实验，不调用生成或 embedding 供应商，不覆盖正式解析、索引、模型缓存和数据库。

## 度量口径

| 指标 | 定义 | 本轮初始门槛 |
| --- | --- | --- |
| 字符错误率 CER | `(替换+删除+插入)/标注字符数`；主指标只移除空白，保留标点、全半角、数字、单位和否定词，不做同义改写；同时保存原始文本 | 普通印刷正文 ≤2%；困难/退化区域 ≤5%；分别报告，不能用大量简单页掩盖困难页 |
| 关键片段检出率 | 在指定区域中精确检出已标注的数字+单位、日期、主体或限制短语；数字边界完整；不是仅搜到一个子串数字 | ≥99%，且冻结的关键数字、单位、否定/例外不得新增错误；小样本另列错误个数 |
| 区域完全正确率 | 指定区域去空白后全文完全一致；用于发现插字、漏字与多识别噪声 | 逐类报告；不以关键片段全部出现替代全文正确 |
| 阅读顺序 | 已标注区域的先后关系正确数/全部应有关系数；缺失区域同时算失败 | ≥98%；只有实际运行版面流水线才计此指标，独立 OCR 的行排序不得冒充 Docling 阅读顺序 |
| 表格归属 | 文本值、行列、表头关联均与人工标注一致的单元格数/已标注格数 | ≥98%；仅按人工框裁剪识字不代表已识别表格结构；未跑结构评估记未验证 |
| 运行开销 | 初始化时间、预热后逐区域/页耗时、中位数/P95、峰值显存、模型/参数/输入哈希 | 单进程峰值≤6.5GiB；同机同输入预热后中位耗时≤small的2倍；初始化单列 |
| 失败与可追溯 | 缺模型、OOM、推理异常、空输出分别计数；保留原图、坐标、原始结果和配置 | 不静默回退CPU，不忽略失败，不用纠错文字冒充OCR原文 |

上述数值是本项目本轮验收目标，不是通用行业基准或当前实测结果。CER 可大于100%；空白区域单独评估误报，不能用空分母制造0%错误。模型置信分不能当作真实正确率。

## 样本与冻结

1. 优先复用本地已保存的真实论文、官方文档和已有扫描样本，记录来源、SHA256、页码与区域坐标。真实扫描、真实排版转栅格、受控合成扫描分别统计。
2. 首轮目标覆盖20至30个页面/区域、多份源文档；实际数量与类别据实报告，不将24个局部区域写成24页全文通过。
3. 标注先于推理。原生文字层只能用于候选转录，必须对照渲染图复核；真实扫描手工转录。标注来源不能来自被测OCR输出。
4. 按源文档划分开发与保留集；保留集在选择参数后一次评价。标注和模型均由实施者可见，因此属于可见保留测试，不宣称独立盲测。派生图/扫描页不得跨分组。
5. 读取顺序、表格结构、图示语义与字符识别分开验收。图中文字识别不能证明箭头或层级理解。

## 对照与切换条件

- A：PP-OCRv6 small，固定现有检测/识别参数和已有权重。
- B：small + 预先声明的区域/分辨率策略；仅在开发集选择，不按保留集结果调参。
- C：PP-OCRv6 medium，使用官方模型清单URL与SHA256校验，检测、识别和字典明确固定；不升级运行依赖。
- 先进行字符识别对照，再核对 Docling 集成可用性；独立OCR成功不代表生产API已切换。
- medium 只有在保留集满足质量门槛、没有新增关键错误、满足资源门槛，且 CER 至少相对降低20%（基线为0时不得恶化），才考虑作为默认替换。否则保留small，medium只作为待选/可选困难区域方案；不能为切换模型修改预期或降低门槛。
- 不做依据标准答案的自动候选选择，不用另一轮相同权重当作独立模型投票。没有可靠的运行时判定规则时不宣称已完成自适应路由。

## 本轮执行边界

实验及下载落在独立 `data/ocr-quality-20261019/`，报告保留首次失败。正式解析版本保持不变。供应商调用账本保持48/80，原额度不用于本地OCR；模型下载是官方权重下载，不是生成请求。若需生产部署，先给出模型质量、集成和显存证据；不能只凭版本名或更多输出字数切换。
