# 阶段01：解析、OCR与结构分块

本页维护解析能力与质量边界，正式版本和运行状态见[接力说明](稳定试用版接力说明.md)。旧解析版本不会因为新代码而自动改写。

## 格式与处理范围

PDF／DOCX／XLSX使用既有Docling／RapidOCR服务，UTF-8 TXT及Markdown在本地解析；DOC／XLS需先转换。工程上传保存原件；统一知识库流程可协调解析、分块和索引，自动索引可能收费。阅读已有结果不重新解析。

规范化结构为docqa-normalized-9，分块structured-heading-table-v6；TXT保持local-text-2，Markdown为local-markdown-3。完整原件、版本、块来源、质量告警与旧索引保持，分块边界修订产生新版本，不直接改证据文字。

Markdown保留标题层级、完整管道表行和表头、代码围栏及行／字符位置。转义竖线和行内代码中的竖线不拆列；代码与正文分开，长代码按物理行续分、保持缩进。超长表行／表头／单行代码明确拒绝并保留旧版本，不静默截断。代码、命令、HTML和链接只作资料，不执行。

## PDF保护与来源

首次解析先检查明显坏映射；命中时保留原件，使用同页同尺寸图像副本交给现有OCR。渲染受页数、像素和提交大小限制，残留明显乱码不得发布新版本。正文恢复不代表公式、上下标、图形关系或数学推导已识别。

新PDF版本区分物理页、目录标签与真实页脚；缺失或冲突不猜印刷页码。数字内联归位仅在同页同栏坐标和原PDF文字层独立支持时进行；保留原节点，未能确认的碎片不强行拼接。XLSX缺公式缓存不当0，不重算公式。

部署参数和现有模型见[Docling部署](../deploy/docling/README.md)，本轮不升级OCR档位或依赖。Markdown原始行目前走文本证据回退，不声称具有PDF／XLSX单元格坐标投影。

## OCR量化标准和历史证据

下列门槛是OCR实验的切换条件，历史成绩只针对原样本，不是当前所有资料准确率。原标准及评分勘误保持。

## 量化与升级标准

| 维度 | 度量与出口 |
| --- | --- |
| 字符 | CER=替换+删除+插入/标注字符；只去空白，保留大小写、数字、标点、单位、否定。排印目标≤2%，真实扫描≤5%。 |
| 关键内容 | 编号、金额、日期、单位、限制等逐项计数；目标≥99%，不新增关键错误。 |
| 阅读顺序 | 使用实际输出树的先后关系，缺失或交错失败；目标≥98%。物理行拼接不算顺序恢复。 |
| 表格 | 值、行列起止、合并跨度、表头属性同时正确；目标≥98%，分原生/扫描报告。空白不是0。 |
| 成本与资源 | 设备总显存≤6.5GiB；完整候选耗时≤基线两倍，包含所有实际阶段。缓存回放不当成推理提速。 |
| 默认切换 | 保留CER相对下降≥20%，上述维度均过关且无待复核分歧；没有新保留验收不能自动升级。 |

CER只覆盖明确转录区域；表格正文另计，不宣称全文字符准确率。数据按原文档/模板分组，退化派生图不能跨组。公开来源是否进入模型训练未知，实施者可见保留不称独立盲测。完整原门槛和冻结文本逐字保留在归档。

## 后续与复现

扫描表格、细框覆盖、长格漏字、阅读顺序和等像素渲染消融仍须新资料／新保留验证；原失败不因局部CER改善被删除。OCR缓存回放不称推理提速。

隔离工具包括run_ocr_profile、run_ocr_layout和run_ocr_pdf_benchmark；执行前读实际参数，默认计划不等于真实转换。输入／模型只读、数据目录隔离，不用正式业务库做实验。

详细历史、原门槛、实际页数、失败与私有证据路径见[逐字快照](archive/2026-10-26-consolidation/docs/阶段01-文档解析与OCR.md)。通用技术文档修复见[修复记录](技术文档RAG与Markdown结构修复记录.md)。
