# 后续能力提升路线

当前顺序和状态统一见[任务书](下一阶段任务书-S2-S5闭环补齐与试点验收.md)，版本／预算见[接力说明](稳定试用版接力说明.md)。此处只保留质量改进原则；旧路线和原验收阈值在[逐字快照](archive/2026-10-26-consolidation/docs/整体能力提升方案.md)。

1. 先修可复现的数据、权限、计费、恢复和引用错误，再作新能力或性能扩展。
2. 检索保全必要双方、定义、条件和冲突，分别检查候选／排序／装入／可见／合法引用，不用扩大预算冒充排序收益。
3. 理解和意图要改变实际执行，保留对象、来源、否定和授权；业务标签准确不代表完整产品能力。
4. 语言按直答、逻辑连贯、条件自然和引用可读验收，不通过删条件或新增付费润色凑分。
5. 新资料／保留集先标注封存；已用于定位的资料算开发回归。报告事实、条件、覆盖和安全错误，不用总平均掩盖关键失败。
6. OCR、数学表示、容量和真实外部工具只在必要证据、样本与授权具备时扩展；不默认更换GPU档位、模型、网关或基础设施。

工程、原文可追溯、语义支持、人工接受和正式运维分别报告；本轮维护不会改变旧失败或重开已关闭的收费计划。
