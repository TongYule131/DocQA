## 设计与历史

产品方案位于[product](product/下一阶段优化计划书.md)，用于理解设计理由和保留需求；实际状态以接力说明和当前任务书为准。旧S2～S5实施说明、能力路线不再维护另一份进度表。

[历史归档索引](archive/README.md)保留冻结计划及整合前正文。归档逐字校验哈希，旧“当前”仅指原日期；业务原件、模型响应和截图仍在私有data目录，不搬入仓库。

运行`python scripts/check_docs.py`检查当前链接、README版本／配置默认值、归档字节及指定冻结清单。状态快照保留原目录语义，不将其旧链接解释为新的导航；当前文档的坏链接仍失败。工具不证明叙述的语义正确或服务持续在线。
