# 阶段01：文档解析与OCR

范围：2026-09-22～09-24 的部署验证、全样本质量检查、Docling接入与修复。原5份报告及工程任务书已完整归档，恢复位置见[文档索引](README.md)。当前工程加固见[阶段05](阶段05-代码审查与加固.md)。

## 已完成

接通 PDF、DOCX、XLSX、UTF-8 TXT 的上传、格式识别、持久化解析任务、结构化预览、来源与质量告警。PDF／Office 使用现有 Docling + RapidOCR 服务，TXT 本地解析；上传不自动解析，解析不自动创建收费索引。

任务、内容质量、索引状态分别保存。解析版本不可变，预览指针与索引指针独立；重新解析或建索引失败不删除旧成功结果。中断后有上游编号直接恢复查询，提交结果不确定时进入 needs_attention，不自动重投。

来源按格式记录：PDF页码／坐标；DOCX章节／表格／结构节点；XLSX工作表／单元格；TXT逻辑页／行号。Office与TXT不伪造PDF物理页码。表格分块保留标题、表头、单位和脚注。

## 验证结论与保留限制

| 层级 | 实际结果及边界 |
| --- | --- |
| OCR GPU | 2026-09-22 服务进程内检测、方向分类、识别三个会话均记录CUDA节点执行。识别仍有2个CPU辅助节点；不能声称全部算子在GPU，也不能据此推断旧首轮设备或加速比。 |
| 七份样本转换 | 5份PDF、1份DOCX、1份XLSX均转换成功；这不代表全文内容准确。 |
| 原件抽查 | DOCX 8段正文、40个表格位置一致；XLSX 72个非公式单元格一致。扫描目录、中文条款顺序、标题与公式仍有缺陷。 |
| 接入独立验收 | 首次12个反例失败；修复后125项离线通过。扫描PDF真实上传、解析、预览、16块1024维索引检索、旧索引保留、新索引切换及重启验证通过。 |
| 真实网页 | 代表性断连、有限退避、刷新、迟到响应、排队禁用、HTML文本化及隐藏敏感错误场景通过；不是全部浏览器／并发场景保证。 |

必须继续显式展示：OCR错字与阅读顺序风险、空白页、空公式、XLSX无缓存公式、目录点线、图片未做语义解析。缺缓存不当作0，不重算公式；页眉页脚保留预览但排除检索。完整表头／注释超预算时受控失败，不能截掉条件后称成功。

仅支持当前已接入格式；旧DOC/XLS、图片、PPTX、图表语义及公式增强不在已验收范围。GPU profiling轮次不作性能基准；旧“首轮一定回退CPU”“OCR加速6.6倍”等结论已撤回。
