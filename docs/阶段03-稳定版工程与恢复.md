## 核心修复和工程里程碑

长TXT按原空白段落形成输入，版本 `local-text-2`，保留行来源；超长单段受控拒绝。修复真实响应非完整结束时丢失最终正文的取证缺口（F18／F19）；不输出模型思考，不接受被截断答案。

2026-10-10补齐真实数据库结构、运行进程和静态资源指纹一致性。未来库、登记断裂、缺列／索引／约束拒绝启动；旧Web遇代码变化返回503，旧worker拒绝继续领取／发请求。legacy只有旧chunks时允许只读预览，不能补造结构来源用于分析。当时工程406项、网页离线21项。

2026-10-12补齐多进程重复提交、竞争领取、租约失效和真实中断证据；F20／F21随后修复PowerShell 5.1脚本编码和UTF-8健康响应解码，5.1／7均实测。新增只读三角色状态面板，退出或连接失败撤下旧就绪结论。早先工程候选441项、网页31项；当前累计回归以[阶段05](阶段05-代码审查与加固.md)552项／51项及隔离三角色浏览器演练为准。

在新的隔离PowerShell会话执行；使用独立目录及假模型配置，仅用固定模型生成演练结果：

```powershell
cd D:\python\DocQA

$env:DOCQA_DATA_DIR = $trialData
$env:DEEPSEEK_API_KEY = 'offline-recovery-fixture'

$env:EMBEDDING_API_KEY = ''
$env:DOCQA_DOCLING_BASE_URL = 'http://127.0.0.1:1'
.\.venv\Scripts\python.exe -X utf8 scripts/seed_recovery_sample.py --data-dir $trialData --run-job
pwsh -File scripts/start_local.ps1 -DataDir $trialData -Port 8123 -NoParseWorker -NoAnalysisWorker
pwsh -File scripts/status_local.ps1 -DataDir $trialData
pwsh -File scripts/stop_local.ps1 -DataDir $trialData
```
